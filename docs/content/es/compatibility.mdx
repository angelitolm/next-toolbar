## Matriz de funciones

| Función | Next 15 | Next 16 | Next 16 + `requestInsights` |
|---|:---:|:---:|:---:|
| Estado HTTP (carga y navegación en el cliente) | ✓ | ✓ | ✓ |
| Patrón de ruta | heurístico | heurístico | exacto |
| Modo de render (Static / Dynamic / Static?) | ✓ | ✓ | ✓ |
| Corrección no-store del modo de render | — | — | ✓ |
| TTFB / tiempo de navegación | ✓ | ✓ | ✓ |
| Tiempo de render en el servidor | — | — | ✓ |
| Fetches del servidor y resultado de caché | — | — | ✓ |
| Errores del servidor | — | — | ✓ |
| Errores del cliente | ✓ | ✓ | ✓ |
| Profiler de peticiones | — | — | ✓ |
| `basePath` / `assetPrefix` | ✓ | ✓ | ✓ |

Los patrones de ruta "heurísticos" se reconstruyen a partir de `usePathname()` y `useParams()`. Aciertan en casi todos los casos; un param cuyo valor coincide con un segmento estático posterior (p. ej. `/blog/blog`) puede etiquetarse mal.

## Qué cambia entre versiones de Next

NextToolbar lee el HMR socket interno de desarrollo de Next, cuya forma cambió entre versiones. La barra las maneja todas:

| | 15.0 | 15.5 | 16.x |
|---|---|---|---|
| Ruta del socket | `/_next/webpack-hmr` | `/_next/webpack-hmr` | `/_next/hmr` |
| Campo del mensaje | `action` | `action` | `type` |
| Mensaje de datos estáticos | `appIsrManifest` | `isrManifest` | `isrManifest` |
| Rutas dinámicas en él | ausentes | ausentes | `false` |
| Request insights | — | — | `requestInsightsUpdate` |

<Callout type="warning" title="API interna">
  Son mensajes internos y no documentados de Next.js. Una versión futura de Next puede cambiarlos; cuando eso ocurra, los segmentos afectados mostrarán `?` en lugar de romper la página.
</Callout>

## Cache Components

Con `cacheComponents` activado (Next 16), Next no envía datos static/dynamic, así que la insignia del modo de render muestra `?`. Todo lo demás funciona.

## Navegadores

| Navegador | Notas |
|---|---|
| Chrome, Edge, Firefox | Soporte completo |
| Safari | No hay `responseStatus` en la Performance API, así que el estado muestra `—`. Todo lo demás funciona. |

## TypeScript

Next 15 no puede cargar `next.config.ts` con **TypeScript 7** (el compilador nativo no tiene API de JavaScript). Usa TypeScript 6 con Next 15, o Next 16.2.11+ para TypeScript 7. Esto afecta a tu app, no a la barra.
